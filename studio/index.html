How the audit works

  1. Opens the site (homepage, contact, booking, FAQ, careers, events, shop) or the channel's public feed.
  2. Checks the signs it can see from outside: forms, booking, chat, quotes, bank transfer, hiring, events, posting gaps.
  3. Ranks the problems, costliest first, and writes the message: main problem, then "I also noticed".
  4. You check the rest yourself (reviews, comments, a test enquiry) and tick what you find. The message updates.
